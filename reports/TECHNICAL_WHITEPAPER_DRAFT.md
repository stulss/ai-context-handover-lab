# 대화 이력 단절 환경에서의 자율 멀티에이전트 컨텍스트 인계 아키텍처 실증 연구
## AI Context Handover Lab: Engineering Case Study & Technical Whitepaper

---

## 1. 프로젝트 및 시스템 개요 (Project Overview)

- **프로덕션 서비스 URL:** https://ai-context-handover-lab.vercel.app/
- **공개 소스 코드 저장소:** https://github.com/stulss/ai-context-handover-lab
- **핵심 연구 가설:** 누적된 대화 기록(Chat History)을 일절 전달하지 않고, 코드베이스와 구조화된 파일시스템 기반 인수인계 프로토콜(Structured Handover Protocol)만으로 후속 에이전트가 소프트웨어 엔지니어링 사이클을 완결할 수 있는가?
- **엔지니어링 파이프라인:** 1차 구현(Agent A, Claude Code) ➡️ 프로토콜 동결 및 상태 인계 ➡️ 2차 구현(Agent B, OpenAI Codex) ➡️ 독립 검증(Validator, Gemini Specialist) ➡️ 프로덕션 CI/CD 배포(Vercel)

---

## 2. 연구 배경 및 문제 정의 (Background & Motivation)

단일 AI 세션에 의존하는 장기 소프트웨어 개발은 컨텍스트 윈도우 한계, 누적 토큰 비용, 그리고 세션 중단이나 모델 교체 시 개발 맥락이 증발하는 '컨텍스트 손실(Context Decay)' 문제에 직면합니다.

본 프로젝트는 대화 전문에 의존하는 기존 프롬프트 체이닝 방식 대신, **Git 저장소의 코드, 고정 수용 테스트 스위트, 명확한 상태 스냅샷, 잔여 백로그(Backlog) 및 수정 금지선(Inviolable Rules)**으로 구성된 표준화된 인계 프로토콜을 설계하고, 이를 실증하기 위해 자체 연구 대시보드 웹 플랫폼을 구축했습니다.

---

## 3. 실험 설계 및 인계 아키텍처 (Experiment Design)

1. **Agent A (시스템 아키텍트):** Next.js 16 기반 연구 대시보드의 아키텍처 스캐폴딩, 도메인 데이터 모델, 컴포넌트 라이브러리 및 기반 테스트 스위트를 구축하고, 엄격한 8회 호출 예산 제약에 도달했을 때 작업을 안전하게 중단했습니다. 중단 직전 `docs/HANDOVER_AI_A_TO_B.md`에 구조화된 7대 인계 프로토콜을 기록했습니다.
2. **Agent B (피처 구현 및 통합 엔지니어):** Agent A의 대화 프롬프트나 맥락 정보 없이 오직 파일시스템과 인계 문서만 수신하는 '콜드 스타트(Cold-Start)' 상태에서 시작했습니다. 기존 테스트 결과를 재현한 후 잔여 요구사항(`/sources`, `/metrics`, `/models`, 404 폴백, 375px 모바일 반응형, `/experiment`, `/tests`)을 완벽히 구현했습니다.
3. **Validator (독립 감사자, agy):** 모든 단위/E2E 테스트 스위트와 렌더링 아티팩트를 제3자 관점에서 독립 감사하고 증거를 보존했습니다.

## 4. 고정 수용 테스트 스위트 (10 Acceptance Criteria Tests)

테스트 계약(Test Contract)의 무결성을 위해 초기 정의된 10개 핵심 검증 기준은 에이전트 간 인계 과정에서도 일체 삭제·수정되지 않았습니다.

| ID | 검증 대상 | 관찰 가능한 기대 동작 (Verifiable Assertion) |
|---|---|---|
| T01 | `/` 대시보드 홈 | 시스템 헤더, 연구 핵심 질문 및 아키텍처 개요 렌더링 |
| T02 | `NAV_LINKS` 7개 | 네비게이션 경로 중복 방지 및 정합성 보장 |
| T03 | `/handover` | 구조화된 7대 인계 프로토콜 규격 및 설계 근거 렌더링 |
| T04 | `/models` | 모델 파라미터 벤치마크 테이블 및 데이터 결측 빈 상태 처리 |
| T05 | `/metrics` | 생산성 6대 지표 및 DORA·SPACE 표준 프레임워크 표시 |
| T06 | 출처 메타데이터 | 외부 링크 누락 시 폴백 렌더링 및 보안 속성 검증 |
| T07 | 수치 결측치 | `null`/`NaN`의 결측치("N/A")와 실제 측정값 `0`의 엄격 분리 |
| T08 | Not-Found (404) | 잘못된 경로 접근 시 복구 네비게이션 및 안내 렌더링 |
| T09 | 모바일 375px 반응형 | 수평 스크롤 오버플로우 방지 및 모바일 테이블 자체 스크롤 검증 |
| T10 | 시스템 무결성 | test, lint, build, typecheck 전체 성공 및 테스트 스킵 0건 |

## 6. 구조화된 7대 인계 프로토콜 (7 Handover Pillars)

1. **목표(Goal):** 완결해야 하는 시스템 사양과 최종 결과물 정의
2. **현재 상태(Current State):** 구현 완료 항목과 미착수 기능의 명확한 경계
3. **실행 명령(Run Commands):** 환경 세팅, 테스트, 린트, 빌드 단일 명령 체계
4. **통과 검사(Passing Tests):** 실측 통과 테스트 건수 및 고유 ID 명시
5. **알려진 이슈(Known Issues):** 재현 절차와 영향받는 모듈 경로 명시
6. **차기 조치(Next Steps):** 우선순위(P0~P2) 기반 실행 로드맵 및 수용 판정선
7. **수정 금지선(Inviolable Rules):** 테스트 검증식 완화 금지, 결측치 임의 채움 금지, 임의 저장소 재초기화 금지

## 7. Agent B 콜드 스타트 및 기능 완결 (Cold-Start & Delivery)

Agent B는 인계 직후 13건의 단위 테스트 PASS를 독립 확인하여 인계 드리프트(Handover Drift)가 없음을 검증했습니다. 이후 도메인 데이터 스키마와 재사용 컴포넌트를 확장하여 잔여 페이지를 완결했습니다.

브라우저 수동 조작 대신 Playwright 기반의 375×812 뷰포트 E2E 자동화 스크립트를 구축하여 모바일 반응형 회귀를 코드 레벨에서 검증했습니다.

- **최종 검증 결과:** Vitest 10개 파일 / 20건 전원 PASS, Playwright E2E 2건 PASS, Lint/Build/Typecheck 무결성 통과
- **수용 기준 달성률:** T01~T10 PASS 10/10 (100%)
- **기존 테스트 무결성:** AI A가 구축한 기존 테스트의 삭제·스킵·단언문 변경 0건

## 10. 엔지니어링 신뢰성 검증 4단계 (4-Step Verification Guide)

1. **접속:** https://ai-context-handover-lab.vercel.app/ 프로덕션 엔드포인트 확인
2. **네비게이션:** 상단 바의 `Context Handover` ➡️ `테스트 현황` ➡️ `실험 기록` 이동
3. **정상 판정:** 7대 인계 프로토콜, T01~T10 전원 녹색 PASS, Agent A ➡️ Handover ➡️ Agent B 타임라인 렌더링 확인
4. **이상 감지:** 404 에러, 레이아웃 깨짐, FAIL 배지, 375px 화면에서의 수평 가로 스크롤 발생 시 결함으로 판정

## 11. 엔지니어링 거버넌스 및 AI 통제 모델 (AI Governance Model)

1. **AI 에이전트 위임 영역:** 초기 아키텍처 스캐폴딩, 인계 문서화, 단위 컴포넌트 구현, E2E 테스트 자동화
2. **엔지니어 직접 통제 영역:** 형상관리 전략, 프로덕션 Vercel 배포, 테스트 계약 정의, 증거 해시 감사
3. **엔지니어링 반려/방어 사례:** 자동 배포 시도 차단, 공식 출처 없는 모델 파라미터 임의 생성(환각) 차단, 미계측 메트릭 임의 보정 차단

## 12. 엔지니어링 컴플라이언스 감사 결과 (Compliance Audit)

- **완전 충족:** 멀티에이전트 순차 실행 통제, 7대 구조화 인계 프로토콜, 무상태 콜드 스타트 재개, 이종 LLM 교차 협업, 테스트 회피 방지, 10/10 PASS 달성, 프로덕션 배포, 시크릿/PII 유출 0건
- **투명한 한계 명시:** 작업 착수 전 통합 시간/비용 공통 상한의 부재, 신규 클린룸 디렉터리 재현 로그 분리 미비, 공개 대시보드의 도구 식별자 노출. 데이터 무결성 원칙에 따라 사후 임의 생성하지 않고 사실 그대로 기록함.

## 13. 결론 및 실무 시사점 (Conclusion & Takeaways)

인계 문서는 단순한 요약 노트가 아니라, **'독립적으로 실행 및 재현 가능한 코드베이스 상태 스냅샷'**이어야 합니다. 

본 연구를 통해 대화 이력 없이도 고정 테스트 계약과 구조화된 파일시스템 기반 인수인계 프로토콜만으로 이종 LLM 에이전트 간의 완벽한 엔지니어링 연속성을 확보할 수 있음을 실증했습니다.
