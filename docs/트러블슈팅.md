# 트러블슈팅 기록

## 기술 백서 PPTX가 PowerPoint에서 열리지 않음

- 발생: AI B가 PptxGenJS로 만든 중간 PPTX를 Microsoft PowerPoint에서 열 수 없었다.
- 확인: `python-pptx`에서는 구조를 읽을 수 있었지만 PowerPoint 호환은 회복되지 않았다. PptxGenJS 버전 변경과 재저장도 같은 증상이었다.
- 해결: 편집 가능한 보고서를 `python-pptx`로 다시 생성하고 PowerPoint COM으로 직접 열어 12쪽을 확인한 뒤 PDF와 PNG로 내보냈다.
- 추가 수정: 작은 카드에서 본문 텍스트 상자 높이가 음수가 되는 계산을 `max(0.1, h - 0.6)`으로 제한했다.
- 최종 판정: `reports/AI_AGENT_HANDOVER_WHITEPAPER.pptx` 열기 성공, PDF 변환 성공, 렌더링 PNG 12장 전수 시각 검수 통과.

## 한글 경고

- 실패한 PptxGenJS 진단 과정의 임시 npm 의존성 감사에서 high 2건이 표시되었다.
- 해당 의존성은 배포 앱 런타임에 포함되지 않았고 최종 생성 방식에도 필요하지 않아, 임시 `reports/node_modules`와 package 파일을 제거했다. `npm audit fix --force`는 실행하지 않았다.
- Playwright의 `NO_COLOR`/`FORCE_COLOR` 메시지는 색상 출력 설정 경고이며, T09 테스트 결과는 2건 모두 PASS다.
